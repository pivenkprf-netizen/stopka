Если это сообщение осталось на экране — файл открыт в режиме предпросмотра, а не в браузере.
В предпросмотре Telegram, «Файлов» и почты приложения не запускаются — работает только картинка.

Как открыть правильно:
  1. iPhone: сохраните файл в «Файлы» → нажмите на него → кнопка «Поделиться» → «Открыть в Safari».
  2. Android: «Загрузки» → нажмите stopka.html → выберите Chrome («Открыть с помощью»).
  3. Из Telegram: «···» → «Открыть в браузере» / «Сохранить в загрузки», затем открыть файл браузером.
  4. Разрешите доступ к камере, когда телефон спросит.

Сканер в телефоне

Стопка

Нажмите «Включить камеру» — телефон спросит разрешение. Дальше лист обводится рамкой активной зоны прямо в кадре и снимается сам.

  • Камера включается одной кнопкой. Если браузер её не даёт — кнопка сразу откроет штатную камеру телефона.
  • Авто-рамка при съёмке, ручные углы с лупой для готовых фото.
  • Архив файлов: PDF и снимки, поиск, избранное, повторная отправка.
  • Всё считается на устройстве, сеть не используется.
Приложение работает даже без камеры: кнопка «Демо-лист» подставляет документ в видоискатель, и весь путь до PDF проходится целиком.

      Архив пуст

      Соберите PDF — он сохранится здесь автоматически.

      Главное
      Камера включается кнопкой

      Вкладка «Камера» → большая кнопка «ВКЛЮЧИТЬ КАМЕРУ» → телефон спросит разрешение → «Разрешить». Если браузер камеру не даёт, кнопка «Камера телефона» откроет обычную камеру устройства — снимок всё равно попадёт в стопку с авто-рамкой.

      Диагностика
      1

      Съёмка

      Авто-спуск снимает, когда рамка устойчива секунду. Свой кадр — выключите авто-спуск и нажмите круглую кнопку. «Ручная рамка» позволяет тянуть углы прямо в видоискателе.

      2

      Точные углы

      В редакторе выберите угол ↖ ↗ ↘ ↙ и двигайте стрелками с шагом 1–12 px. У каждого параметра есть − и +.

      3

      PDF и архив

      Отметьте страницы → «Собрать PDF» → «Поделиться» → Telegram. Файл останется в «Архиве».

      Если камера не включается
      ?

      Файл открыт не в браузере

      Предпросмотр Telegram и «Файлов» не запускает приложения. Откройте stopka.html через Safari или Chrome.

      ?

      Нужен https

      Живой видоискатель браузер разрешает по https или на localhost. При открытии файла с диска используйте «Камера телефона» — она работает всегда.

      ?

      Разрешение запрещено

      iPhone: Настройки → Safari → Камера → «Спросить». Android: замок в адресной строке → Разрешения → Камера.

      Сохранить приложение

      stopka.html

      Иконка на экран: iPhone — Safari → «Поделиться» → «На экран „Домой“». Android — Chrome → ⋮ → «Установить приложение».
